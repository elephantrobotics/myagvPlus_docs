6.1.4 Controlling Car Movement

Controlling AGV Movement

Through the motion control interfaces provided by MyAGVPlus, you can easily control the omnidirectional Mecanum wheel chassis to perform translation, backward movement, and in-place rotation operations.

1 Interface Description

All movement commands require a speed parameter, and its valid range is 0.01 to 1.50 (m/s). For safety reasons, if the speed setting exceeds this range, the system will report an error.

Common motion interfaces are as follows:

  • move_forward(speed): Control the AGV to translate forward
  • move_backward(speed): Control the AGV to translate backward
  • move_left_lateral(speed): Control the AGV to translate laterally to the left
  • move_right_lateral(speed): Control the AGV to translate laterally to the right
  • turn_left(speed): Control the AGV to rotate in place to the left
  • turn_right(speed): Control the AGV to rotate in place to the right
  • stop(): Emergency brake to stop all movements, instantly resetting wheel speeds to zero

2 Simple Demonstration

Create a new Python file named control_move.py and enter the following code:

from pymycobot.myagvplus import MyAGVPlus
import time

# Initialize the MyAGVPlus object
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# Turn on the robot (powers on the relay and enables motors, wait about 6 seconds for motor startup)
agv.power_on()

speed = 0.5 # Set a uniform movement speed of 0.5 m/s

print("Translating forward...")
agv.move_forward(speed)
time.sleep(2)
agv.stop()
time.sleep(1)

print("Rotating left in place...")
agv.turn_left(speed)
time.sleep(2)
agv.stop()
time.sleep(1)

print("Translating laterally to the right...")
agv.move_right_lateral(speed)
time.sleep(2)
agv.stop()

# Test completed, power off the robot and disable motors
agv.power_off()

3 Run the Example File

Run the code by entering the following command in the terminal:

python3 control_move.py

After execution, the AGV chassis will sequentially demonstrate forward translation, left rotation, and right lateral translation, with brief stops buffering between each action.
