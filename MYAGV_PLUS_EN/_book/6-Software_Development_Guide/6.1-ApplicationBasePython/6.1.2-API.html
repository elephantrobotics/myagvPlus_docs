6.1.2 API Usage Instructions

MyAGV Plus API Instructions

Note: The following APIs are all Python APIs. Please install the pymycobot Python SDK package before use.

1. System & Product Information

get_system_version()

  • Function: Get the main firmware version number
  • Return Value: float (Version number)

get_modify_version()

  • Function: Get the sub firmware version number (precision fixed, returns the real value directly)
  • Return Value: float (Version number)

set_debug_state(state)

  • Function: Set the debug state
  • Parameters:
    • state (int): 0-Battery, 1-Gyroscope, 2-LED, 4-Command
  • Return Value: int (1: Success, 0: Failure)

get_debug_state()

  • Function: Get the current debug state
  • Return Value: int (Current debug state bit)

power_on()

  • Function: Turn on the robot (turns on the relay and enables all motors, initialized to velocity control mode)
  • Return Value: int (1: Success, 0: Failure)

power_on_only()

  • Function: Only turn on the robot relay (does not enable motors)
  • Return Value: int (1: Success, 0: Failure)

power_off()

  • Function: Turn off the robot (disables motors and turns off the relay power)
  • Return Value: int (1: Success, 0: Failure)

is_power_on()

  • Function: Check if the robot power is turned on
  • Return Value: int (1: Power on, 0: Power off)

get_robot_status()

  • Function: Read the robot hardware abnormal state information
  • Return Value: list[int] [Battery state, Gyroscope state, Power level]
    • Battery state: 0-Normal, 1-Abnormal
    • Gyroscope state: 0-Normal, 1-Abnormal
    • Power level: 0-Normal, 1-Warning(<=19.6V), 2-Low power(<19V)

2. Motion Control

Note:

  1. The valid range for the speed parameter of the following translation and rotation commands is 0.01 ~ 1.5 m/s. Passing out-of-bounds parameters will directly trigger a ValueError.
  2. Safety Interlock Mechanism: When motion commands are issued, if the target speed of any wheel is 0 (e.g., passed abnormally), the underlying layer will instantly force all wheel speeds to 0 to prevent slipping out of control.

move_forward(speed)

  • Function: Translate the robot forward
  • Return Value: int (1: Success, 0: Failure)

move_backward(speed)

  • Function: Translate the robot backward
  • Return Value: int (1: Success, 0: Failure)

move_left_lateral(speed)

  • Function: Translate the robot laterally to the left
  • Return Value: int (1: Success, 0: Failure)

move_right_lateral(speed)

  • Function: Translate the robot laterally to the right
  • Return Value: int (1: Success, 0: Failure)

turn_left(speed)

  • Function: Rotate in place to the left
  • Return Value: int (1: Success, 0: Failure)

turn_right(speed)

  • Function: Rotate in place to the right
  • Return Value: int (1: Success, 0: Failure)

stop()

  • Function: Stop all movements
  • Return Value: int (1: Success, 0: Failure)

set_auto_report_state(state)

  • Function: Set the auto-report state of underlying data
  • Parameters: state (int): 0-Off, 1-On
  • Return Value: int (1: Success, 0: Failure)

get_auto_report_state()

  • Function: Get the current auto-report state
  • Return Value: int (0: Off, 1: On)

get_auto_report_message()

  • Function: Passively get the latest auto-report data parsing result (features underlying sliding window high-frequency anti-misalignment parsing)
  • Return Value: list
    • 0: (list[int]) Machine state [Battery state, Gyroscope state, Power level]
    • 1: (float) Battery voltage 1
    • 2: (float) Battery voltage 2
    • 3: (int) Charge state
    • 4: (list[float]) 18-byte fully parsed gyroscope data (3-axis acceleration, 3-axis angular velocity, Pitch/Roll/Yaw Euler angles)
    • 5: (list[int]) Motor state (Status codes of the 4 motors)
    • 6: (int) Motor enable state (0: Enabled, 1: Disabled)

3. Motor Auxiliary Control

set_motor_enable(motor_id, state)

  • Function: Set the enable state of the motor
  • Parameters:
    • motor_id (int): 1~4 represents a single motor, 254 represents all four motors
    • state (int): 0-Disable, 1-Enable
  • Return Value: int (1: Success, 0: Failure)

get_motor_enable_status()

  • Function: Get the enable state of all motors (judges whether online based on temperature)
  • Return Value: list[int] [m1, m2, m3, m4] (0-Disabled/Offline, 1-Enabled/Online)

get_motor_status()

  • Function: Get the hardware error status code of each DM motor (if an abnormality is encountered, a detailed warning will be automatically printed in the terminal along with self-healing command prompts)
  • Return Value: list[int] [m1, m2, m3, m4] (0 is normal, others are error codes)

clear_motor_error(motor_id)

  • Function: [New] Motor abnormal deadlock self-healing interface. Performs an instantaneous power-off, reset, and restoration of the online state for the motor reporting an error.
  • Parameters: motor_id (int): 1~4 or 254
  • Return Value: int (1: Success)

set_motor_zero_position(motor_id)

  • Function: [New] One-key reset of the specified DM wheel's current position to the mechanical zero point
  • Parameters: motor_id (int): 1~4
  • Return Value: int (1: Success)

get_motor_temps()

  • Function: Get the current MOS temperature of each motor
  • Return Value: list[float] [m1, m2, m3, m4]

get_motor_positions()

  • Function: [New] Get the current precise rotational mileage position of the motor (in radians)
  • Return Value: list[float] [m1, m2, m3, m4]

get_motor_speeds()

  • Function: Get the current rotational speed of the motor (with a ±0.1 deadband hardware noise reduction filter applied)
  • Return Value: list[float] [m1, m2, m3, m4]

get_motor_torques()

  • Function: Get the current output torque of the motor (with a ±0.1 deadband hardware noise reduction filter applied)
  • Return Value: list[float] [m1, m2, m3, m4]

get_motor_loss_count()

  • Function: Get the packet loss count of each motor during CAN communication (real-time analysis of intercepted send/receive data packets)
  • Return Value: list[int] [m1, m2, m3, m4]

change_motor_param(motor_id, rid, value)

  • Function: Temporarily modify the DM motor advanced internal control register
  • Parameters:
    • motor_id (int): 1-4
    • rid: Target parameter ID (see DM manual for details)
    • value: Parameter value to be written

read_motor_param(motor_id, rid)

  • Function: Read the specified advanced parameter of the DM motor
  • Parameters:
    • motor_id (int): 1-4
    • rid: Target parameter ID

save_motor_param(motor_id)

  • Function: Permanently solidify and save the modified DM motor parameters to Flash, which will not be lost after power-off
  • Parameters: motor_id (int): 1-4
  • Return Value: int (1: Success)

4. IO Control and Communication

set_led_mode(mode)

  • Function: Set the LED mode
  • Parameters: mode (int): 0-Battery indicator mode (default), 1-DIY custom mode
  • Return Value: int (1: Success, 0: Failure)

set_led_color(brightness, color)

  • Function: Set DIY LED color (requires calling set_led_mode(1) first to switch to DIY mode)
  • Parameters:
    • brightness (int): Brightness 0 - 255
    • color (tuple): RGB tuple (R, G, B)
  • Return Value: int (1: Success, 0: Failure)

get_pin_input(pin)

  • Function: Get input IO state
  • Parameters: pin (int): Pin number 1 - 6
  • Return Value: int (Current level state; -1 for read failure or non-existent pin)

set_pin_output(pin, state)

  • Function: Set output IO level
  • Parameters:
    • pin (int): 1 - 6
    • state (int): 0-Low level, 1-High level
  • Return Value: int (1: Success, 0: Failure)

get_estop_state()

  • Function: Get the emergency stop button state
  • Return Value: int (0: Released/Not pressed, 1: In pressed state, -1: Read failure)

set_communication_state(state)

  • Function: Switch the underlying communication state mode. When switched to 1 (Socket), the local serial port will be intelligently released.
  • Parameters: state (int): 0-Serial communication (default), 1-Socket communication, 2-Bluetooth communication (writes local MAC)
  • Return Value: int (1: Success, 0: Failure)

get_communication_state()

  • Function: Get the current communication state
  • Return Value: int (0-Serial, 1-Socket, 2-Bluetooth)

5. WiFi & Bluetooth

get_wifi_ip_port()

  • Function: Get the Wi-Fi IP and port of the Jetson device
  • Return Value: tuple(str, int) ("IP Address", 8080)

get_wifi_account()

  • Function: Get the name of the currently connected Wi-Fi account
  • Return Value: tuple(str, str) ("SSID", "******")

get_bluetooth_address()

  • Function: Get the local Bluetooth MAC address
  • Return Value: str (Bluetooth MAC)

get_bluetooth_uuid()

  • Function: Get Bluetooth UUID and service information
  • Return Value: tuple(str, str, str) (Bluetooth Name, Service UUID, Characteristic UUID)

6. Usage Examples

6.1 Get the system version number of AGVPlus

from pymycobot import MyAGVPlus

# Initialize the AGVPlus object (requires passing the DM motor serial port and ESP32 control serial port)
agv_plus = MyAGVPlus("/dev/myagvplus_controller", baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# Get the main firmware version number
version = agv_plus.get_system_version()
print(version)

6.2 Control AGVPlus to move forward at 0.5m/s and turn on the red LED light

import time
from pymycobot import MyAGVPlus

agv_plus = MyAGVPlus("/dev/myagvplus_controller", baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# Turn on the robot (includes relay power-on and motor enabling processes, wait a few seconds)
agv_plus.power_on()

# Switch LED to DIY mode
agv_plus.set_led_mode(1)
# Set LED color to red (brightness 255)
agv_plus.set_led_color(255, (255, 0, 0))

# Control AGVPlus to move forward at 0.5m/s
agv_plus.move_forward(0.5)

# Sleep for 3 seconds
time.sleep(3)

# Stop moving
agv_plus.stop()

# Turn off robot power and disable motors
agv_plus.power_off()

6.3 Get network information and switch communication mode to Socket

from pymycobot import MyAGVPlus

agv_plus = MyAGVPlus("/dev/myagvplus_controller", baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# Get the WIFI account of AGVPlus
account, password = agv_plus.get_wifi_account() 
print(f"Account: {account}, Password: {password}")

# Get the IP address and open port of AGVPlus
ip, port = agv_plus.get_wifi_ip_port()
print(f"IP: {ip}, Port: {port}")

# Set the current communication mode to Socket mode
set_result = agv_plus.set_communication_state(1)
if set_result == 1:
    print("Set communication mode to Socket successfully.")
else:
    print("Failed to set communication mode to Socket.")

6.4 [Must Read] Start and use the Socket daemon for seamless remote control

Socket mode allows you to control the AGV with zero latency from any computer connected to the same LAN, perfectly supporting secondary development.

Step 1: Start the network daemon on the robot motherboard (Jetson Nano) Open the terminal and run the following command. The process will run automatically and "lurk" in the background, continuously monitoring the communication status:

python3 agv_socket_server.py

(Note: It is not recommended to manually use local serial scripts to forcibly control the hardware while this program is running, unless the serial port is released first.)

Step 2: Trigger network service takeover via code commands In another terminal or directly through your code, call the following statement (as shown in example 6.3):

agv_plus.set_communication_state(1)

The underlying layer will immediately release the usage rights of the physical serial port! At the same time, the background agv_socket_server.py detects the state change, instantly takes over the physical hardware, and exposes the 9000 network port.

Step 3: Issue commands on the remote personal computer just like calling a local library On a personal computer (Win/Mac/Linux) within the LAN:

from pymycobot.myagvplussocket import MyAGVPlusSocket
import time

# Connect to the robot IP and specify port 9000
agv = MyAGVPlusSocket("192.168.1.132", 9000)

print(agv.get_motor_speeds()) # Remotely read speed information
agv.move_left_lateral(0.3)    # Remotely control left lateral movement
time.sleep(2)
agv.stop()
