# Controlling RGB Lights

Through the lighting control interfaces provided by `MyAGVPlus`, you can take over the LED strips around the chassis and customize your preferred colors and brightness.

## 1 Interface Description

Controlling the RGB LED strips mainly involves two interfaces:

- `set_led_mode(mode)`: Set the LED mode. `0` represents restoring the system's default battery marquee indication mode, and `1` represents switching to the developer's custom color control mode.
- `set_led_color(brightness, color)`: In custom mode, set the brightness and color of the LED strips. The `brightness` range is 0-255, and `color` is a tuple containing the three RGB colors, such as `(255, 0, 0)` representing pure red.

## 2 Simple Demonstration

Create a new Python file named `control_rgb.py` and enter the following code:

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# Initialize the MyAGVPlus object
# The serial port path depends on the actual device, such as /dev/myagvplus_controller and /dev/ttyACM0
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# Only turn on the underlying relay motherboard power (motor enabling is not required for testing lights)
agv.power_on_only()

print("Switching LED to custom control mode")
agv.set_led_mode(1)
time.sleep(0.5)

print("Setting the light color to: Red")
agv.set_led_color(255, (255, 0, 0))
time.sleep(2)

print("Setting the light color to: Green")
agv.set_led_color(255, (0, 255, 0))
time.sleep(2)

print("Setting the light color to: Blue")
agv.set_led_color(255, (0, 0, 255))
time.sleep(2)

print("Restoring the system default battery indicator mode")
agv.set_led_mode(0)

# Test completed, turn off the power
agv.power_off()
```

## 3 Run the Example File

Run the code by entering the following command in the terminal:

```bash
python3 control_rgb.py
```

After execution, the chassis LED strips will sequentially display bright red, pure green, and pure blue for 2 seconds each, and then restore the default battery marquee indication effect.
