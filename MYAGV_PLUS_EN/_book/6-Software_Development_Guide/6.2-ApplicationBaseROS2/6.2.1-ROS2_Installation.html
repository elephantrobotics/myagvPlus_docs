6.2.1 Installation and Environment Setup

ROS2 Installation

  • 1.Configure your Ubuntu repositories

Configure your Ubuntu repositories to allow "restricted," "universe," and "multiverse." You can follow the Ubuntu guide for instructions on doing this.

  • 2.Setup your sources.list

Setup your computer to accept software from packages.ros.org.

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
  • 3.Set up your keys
sudo apt install curl -y
curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
  • 4.Installation

First, make sure your Debian package index is up-to-date:

sudo apt update

Now, choose which version of ROS2 to install. The following example uses ROS2 Humble.

Desktop-Full Install (Recommended) :Everything in Desktop plus 2D/3D simulators and 2D/3D perception packages

sudo apt install ros-humble-desktop-full

Desktop Install: All content in ROS2-Base, as well as the following tools rqt and rviz2

sudo apt install ros-humble-desktop

ROS2-Base: (Bare Bones) ROS 2 core packaging, building, and communication library. No graphical interface tools.

sudo apt install ros-humble-ros-base

There are more available packages in ROS2. You can install specific packages directly.

sudo apt install ros-humble-PACKAGE

e.g.

sudo apt install ros-humble-slam-toolbox

To find available packages, please refer to ROS2 Index or use

apt search ros-humble
  • 5.Environment setup

You must source this script in every bash terminal you use ROS in.

source /opt/ros/humble/setup.bash

It can be convenient to automatically source this script every time a new shell is launched. These commands will do that for you.

Bash

echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
