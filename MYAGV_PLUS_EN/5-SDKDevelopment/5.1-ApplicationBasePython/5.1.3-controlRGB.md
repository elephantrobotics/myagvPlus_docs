# Controlling RGB Lighting

Through the lighting control interfaces provided by `MyAGVPlus`, you can take control of the LED strips surrounding the chassis and customize their color and brightness to your preference.

## 1 Interface Description

Controlling the RGB LED strips primarily involves two interfaces:

- `set_led_mode(mode)`: Sets the LED mode. `0` restores the system's default "battery level marquee" mode, while `1` switches to the developer-defined custom color mode.
- `set_led_color(brightness, color)`: Sets the brightness and color of the LED strips while in custom mode. The `brightness` value ranges from 0 to 255, and `color` is a tuple containing the three RGB color components—for example, `(255, 0, 0)` represents pure red. ## 2 Simple Demonstration

Create a new Python file named `control_rgb.py` and enter the following code:

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# Initialize the MyAGVPlus object
# The serial port path depends on your specific device (e.g., /dev/myagvplus_controller or /dev/ttyUSB0)
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyUSB0', esp32_baud=115200, debug=True)

# Enable power only to the underlying relay board (testing the lights does not require enabling the motors,
# so we use `power_on_only`)
agv.power_on_only()

print("Switching LED to custom control mode")
agv.set_led_mode(1)
time.sleep(0.5)

print("Setting light color to: Red")
agv.set_led_color(255, (255, 0, 0))
time.sleep(2)

print("Setting light color to: Green")
agv.set_led_color(255, (0, 255, 0))
time.sleep(2)

print("Setting light color to: Blue")
agv.set_led_color(255, (0, 0, 255))
time.sleep(2)

print("Restoring system default battery indicator mode")
agv.set_led_mode(0)

# Task complete; cut off power
agv.power_off()
```

## 3 Running the Example File

Enter the following command in your terminal to run the code:

```bash
python3 control_rgb.py
```

Upon execution, the LED strip on the robot's chassis will sequentially display bright red, pure green, and pure blue—each for 2 seconds—before reverting to the default battery-level "marquee" indicator effect. ---
