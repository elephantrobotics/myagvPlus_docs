# Configuration 

pymycobot is a Python package for serial communication with the robot car. It supports Python 2, Python 3.5, and later versions. 

Before using pymycobot, please ensure that you have set up a Python environment. Follow the steps below to install Python. 

## 1 Download and Install Python 

Currently, Python has two versions: 2.x and 3.x. These two versions are not compatible with each other. This section uses version 3.x as an example because it is becoming increasingly popular. 

### 1.1 Installing Python 

The Jetson Nano comes with Ubuntu (V-22.04) and a built-in Python development environment, eliminating the need for separate setup and management. 

## 2 Preparation 

Enter the following command in the terminal to install or update: 

```bash
pip install --upgrade pymycobot
```

## 3 Simple Demonstration 

Create a new Python file and enter the following code. 

```python
from pymycobot.myagvplus import MyAGVPlus
import time


# Initialize the MyAGVPlus object  
# Note: Motor control serial port and ESP32 serial port must be provided; specific serial port paths depend on actual device configuration agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyUSB0', esp32_baud=115200, debug=True)


# Enable robot (automatically powers on the relay and enables the motor; after calling, the program includes an internal wait of approximately 6 seconds to allow the motor to start and calibrate) agv.power_on()


# Set the movement speed (range: 0.01 to 1.50 m/s)
speed = 0.5 

print("Move forward") agv.move_forward(speed)
time.sleep(2)  # pause for 2 seconds agv.stop()
time.sleep(0.5) 

print("Move backward") agv.move_backward(speed)
time.sleep(2)
agv.stop()
time.sleep(0.5) 

print("Move horizontally to the left") agv.move_left_lateral(speed)
time.sleep(2)
agv.stop()
time.sleep(0.5) 

print("Move horizontally to the right") agv.move_right_lateral(speed)
time.sleep(2)
agv.stop()


Operation complete. Turn off the robot power and disable the motors. agv.power_off()
```


## 4 Running Example Files: 

```bash
python3 move_agv.py
```


By default, this example script controls the AGV to move in four different directions for 2 seconds each.
