# Configuration

`pymycobot` is a Python package used for serial communication with the robot. It supports Python 2, Python 3.5, and later versions.

Before using `pymycobot`, please ensure that a Python environment is set up. Follow the steps below to install Python.

## 1 Download and Install Python

Currently, there are two versions of Python: 2.x and 3.x. These two versions are mutually incompatible. This section uses version `3.x` as an example because it is becoming increasingly popular.

### 1.1 Install Python

The Jetson Nano version comes with an Ubuntu (V-22.04) system and a built-in Python development environment, so there is no need to build and manage it separately.

## 2 Preparations

Enter the following command in the terminal to install or update the package:

```bash
pip install --upgrade pymycobot
```

## 3 Simple Demonstration

Create a new Python file and enter the following code.

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# Initialize the MyAGVPlus object
# Note that you need to pass in the motor control serial port and the ESP32 serial port.
# The specific serial port path depends on the actual device.
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# Turn on the robot (automatically turns on the relay power and enables the motors; 
# after calling, the program has a built-in wait of about 6 seconds for motor startup and calibration)
agv.power_on()

# Set movement speed (range is 0.01 to 1.50 m/s)
speed = 0.5 

print("Moving forward")
agv.move_forward(speed)
time.sleep(2)  # Lasts for 2 seconds
agv.stop()
time.sleep(0.5)

print("Moving backward")
agv.move_backward(speed)
time.sleep(2)
agv.stop()
time.sleep(0.5)

print("Moving left laterally")
agv.move_left_lateral(speed)
time.sleep(2)
agv.stop()
time.sleep(0.5)

print("Moving right laterally")
agv.move_right_lateral(speed)
time.sleep(2)
agv.stop()

# Test completed, turn off the robot power and disable the motors
agv.power_off()
```

## 4 Run the Example File

```bash
python3 move_agv.py
```

By default, this example script will control the AGV to move in four different directions for 2 seconds each.
