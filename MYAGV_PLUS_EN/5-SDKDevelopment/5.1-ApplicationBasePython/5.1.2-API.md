# MyAGV Plus API Usage Guide

> **Note:** All APIs listed below are Python APIs. Please install the `pymycobot` Python SDK package before use. ***

## 1. System & Product Information

### get\_system\_version()

- **Function:** Retrieves the main firmware version number.
- **Return Value:** `float` (Version number)

### get\_modify\_version()

- **Function:** Retrieves the minor firmware version number (precision has been corrected; returns the actual value directly).
- **Return Value:** `float` (Version number)

### set\_debug\_state(state)

- **Function:** Sets the debug state.
- **Parameters:**
- `state` (int): 0 - Battery, 1 - Gyroscope, 2 - LED, 4 - Commands
- **Return Value:** `int` (1: Success, 0: Failure)

### get\_debug\_state()

- **Function:** Retrieves the current debug state.
- **Return Value:** `int` (Current debug state bitmask)

### power\_on()

- **Function:** Powers on the robot (activates the relay, enables all motors, and initializes to velocity control mode).
- **Return Value:** `int` (1: Success, 0: Failure)

### power\_on\_only()

- **Function:** Activates only the robot's relay (does not enable the motors).
- **Return Value:** `int` (1: Success, 0: Failure)

### power\_off()

- **Function:** Powers off the robot (disables the motors and cuts power to the relay).
- **Return Value:** `int` (1: Success, 0: Failure)

### is\_power\_on()

- **Function:** Checks whether the robot's power is currently on.
- **Return Value:** `int` (1: On, 0: Off)

### get\_robot\_status()

- **Function:** Reads information regarding the robot's hardware anomaly status.
- **Return Value:** `list[int]` `[Battery Status, Gyroscope Status, Battery Level]`
- Battery Status: 0 - Normal, 1 - Abnormal
- Gyroscope Status: 0 - Normal, 1 - Abnormal
- Battery Level: 0 - Normal, 1 - Warning (<= 19.6V) 2 - Low Battery (<19V)

## 2. Motion Control

> **Note:**
>
> 1. The valid range for the `speed` parameter in the following movement and rotation commands is **0.01 – 1.5 m/s**. Passing a parameter outside this range will immediately raise a `ValueError`.
> 2. **Safety Interlock Mechanism:** When a motion command is issued, if the target speed of *any* individual wheel is 0 (e.g., due to an erroneous input), the underlying system will instantly and forcibly reset the speed of *all* wheels to 0 to prevent slippage and loss of control. ### move\_forward(speed)

- **Function:** Translate the robot forward
- **Return Value:** `int` (1: Success, 0: Failure)

### move\_backward(speed)

- **Function:** Translate the robot backward
- **Return Value:** `int` (1: Success, 0: Failure)

### move\_left\_lateral(speed)

- **Function:** Translate the robot to the left
- **Return Value:** `int` (1: Success, 0: Failure)

### move\_right\_lateral(speed)

- **Function:** Translate the robot to the right
- **Return Value:** `int` (1: Success, 0: Failure)

### turn\_left(speed)

- **Function:** Rotate the robot left in place
- **Return Value:** `int` (1: Success, 0: Failure)

### turn\_right(speed)

- **Function:** Rotate the robot right in place
- **Return Value:** `int` (1: Success, 0: Failure)

### stop()

- **Function:** Stop all movement
- **Return Value:** `int` (1: Success, 0: Failure)

### set\_auto\_report\_state(state)

- **Function:** Set the automatic reporting state for low-level data
- **Parameter:** `state` (int): 0 - Off, 1 - On
- **Return Value:** `int` (1: Success, 0: Failure)

### get\_auto\_report\_state()

- **Function:** Get the current automatic reporting state
- **Return Value:** `int` (0: Off, 1: On)

### get\_auto\_report\_message()

- **Function:** Passively retrieve the parsed results of the latest automatic report data (features high-frequency, anti-misalignment parsing via a low-level sliding window)
- **Return Value:** `list`
- `0`: (list\[int]) Robot Status `[Battery Status, Gyroscope Status, Battery Level]`
- `1`: (float) Battery Voltage 1
- `2`: (float) Battery Voltage 2
- `3`: (int) Charging Status
- `4`: (list[float]) Fully parsed gyroscope data (18 bytes), comprising 3-axis acceleration, 3-axis angular velocity, and Pitch/Roll/Yaw Euler angles.
- `5`: (list[int]) Motor Status (Status codes for the 4 motors).
- `6`: (int) Motor Enable Status (0: Enabled, 1: Disabled).

## 3. Motor Auxiliary Control

### set\_motor\_enable(motor\_id, state)

- **Function:** Sets the enable status of a motor.
- **Parameters:**
- `motor_id` (int): 1–4 represents a single motor; 254 represents all four motors.
- `state` (int): 0—Disabled, 1—Enabled.
- **Return Value:** `int` (1: Success, 0: Failure).

### get\_motor\_enable\_status()

- **Function:** Retrieves the enable status of all motors (determines "online" status based on temperature readings).
- **Return Value:** `list[int]` `[m1, m2, m3, m4]` (0—Disabled/Offline, 1—Enabled/Online).

### get\_motor\_status()

- **Function:** Retrieves the hardware error status codes for each DM motor (if an anomaly is detected, a detailed warning will be automatically printed to the terminal, along with a prompt for the self-recovery command).
- **Return Value:** `list[int]` `[m1, m2, m3, m4]` (0 indicates normal operation; other values ​​are error codes).

### clear\_motor\_error(motor\_id)

- **Function:** [New] Motor Anomaly Self-Recovery Interface. Instantly cuts power to the reporting motor, resets it, and restores it to an online state. - **Parameters:** `motor_id` (int): 1–4 or 254
- **Return Value:** `int` (1: Success)

### set\_motor\_zero\_position(motor\_id)

- **Function:** [New] Resets the current position of the specified DM wheel to its mechanical zero point with a single command.
- **Parameters:** `motor_id` (int): 1–4
- **Return Value:** `int` (1: Success)

### get\_motor\_temps()

- **Function:** Retrieves the current temperature of the MOS transistors for each motor.
- **Return Value:** `list[float]` `[m1, m2, m3, m4]`

### get\_motor\_positions()

- **Function:** [New] Retrieves the current high-precision rotational position (in radians) for each motor.
- **Return Value:** `list[float]` `[m1, m2, m3, m4]`

### get\_motor\_speeds()

- **Function:** Retrieves the current rotational speed of each motor (hardware noise filtering with a ±0.1 deadband has been applied).
- **Return Value:** `list[float]` `[m1, m2, m3, m4]`

### get\_motor\_torques()

- **Function:** Retrieves the current output torque of each motor (hardware noise filtering with a ±0.1 deadband has been applied).
- **Return Value:** `list[float]` `[m1, m2, m3, m4]`

### get\_motor\_loss\_count()

- **Function:** Retrieves the packet loss count for each motor during CAN communication (based on real-time analysis and interception of transmitted and received packets).
- **Return Value:** `list[int]` `[m1, m2, m3, m4]`

### change\_motor\_param(motor\_id, rid, value)

- **Function:** Temporarily modifies the advanced internal control registers of a DM motor.
- **Parameters:**
- `motor_id` (int): 1–4
- `rid`: Target parameter ID (see the DM manual for details)
- `value`: The parameter value to be written

### read\_motor\_param(motor\_id, rid)

- **Function:** Reads a specified advanced parameter from a DM motor.
- **Parameters:**
- `motor_id` (int): 1-4
- `rid`: Target parameter ID.

### save\_motor\_param(motor\_id)

- **Function:** Permanently saves modified DM motor parameters to Flash memory; parameters are retained even after power-off.
- **Parameters:** `motor_id` (int): 1-4
- **Return Value:** `int` (1: Success)

## 4. IO Control and Communication

### set\_led\_mode(mode)

- **Function:** Sets the LED mode.
- **Parameters:** `mode` (int): 0 - Battery Level Indication Mode (Default), 1 - DIY Custom Mode.
- **Return Value:** `int` (1: Success, 0: Failure)

### set\_led\_color(brightness, color)

- **Function:** Sets the DIY LED color (requires calling `set_led_mode(1)` first to switch to DIY mode).
- **Parameters:**
- `brightness` (int): Brightness level (0 - 255).
- `color` (tuple): RGB tuple `(R, G, B)`.
- **Return Value:** `int` (1: Success, 0: Failure)

### get\_pin\_input(pin)

- **Function:** Retrieves the status of an input IO pin.
- **Parameters:** `pin` (int): Pin number (1 - 6).
- **Return Value:** `int` (Current logic level; -1 indicates read failure or non-existent pin).

### set\_pin\_output(pin, state)

- **Function:** Sets the logic level of an output IO pin.
- **Parameters:**
- `pin` (int): 1 - 6
- `state` (int): 0 - Low Level, 1 - High Level.
- **Return Value:** `int` (1: Success, 0: Failure)

### get\_estop\_state()

- **Function:** Retrieves the status of the Emergency Stop button.
- **Return Value:** `int` (0: Released/Not Pressed, 1: Pressed state, -1: Read failed)

### set\_communication\_state(state)

- **Function:** Switches the underlying communication mode. When switched to `1` (Socket), the local serial port is intelligently released.
- **Parameters:** `state` (int): 0 - Serial Communication (Default), 1 - Socket Communication, 2 - Bluetooth Communication (Writes local MAC)
- **Return Value:** `int` (1: Success, 0: Failure)
