# Controlling the Robot's Movement

Through the motion control interfaces provided by `MyAGVPlus`, you can easily control the omnidirectional Mecanum-wheel chassis to perform operations such as lateral translation, moving backward, and rotating in place.

## 1 Interface Description

All movement commands require passing a `speed` parameter; the valid range for this parameter is **0.01 to 1.50 (m/s)**. For safety reasons, the system will generate an error if the specified speed falls outside this valid range. Common motion interfaces are as follows:
- `move_forward(speed)`: Controls the AGV to translate forward.
- `move_backward(speed)`: Controls the AGV to translate backward.
- `move_left_lateral(speed)`: Controls the AGV to translate laterally to the left.
- `move_right_lateral(speed)`: Controls the AGV to translate laterally to the right.
- `turn_left(speed)`: Controls the AGV to rotate left in place.
- `turn_right(speed)`: Controls the AGV to rotate right in place.
- `stop()`: Performs an emergency stop to halt all motion, instantly bringing wheel speeds to zero.

## 2 Simple Demonstration

Create a new Python file named `control_move.py` and enter the following code:

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# Initialize the MyAGVPlus object
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyUSB0', esp32_baud=115200, debug=True)

# Power on the robot (energizes the relay and enables the motors; wait approx. 6 seconds for the motors to start up)
agv.power_on()

speed = 0.5 # Set a uniform motion speed of 0.5 m/s

print("Translating forward...")
agv.move_forward(speed)
time.sleep(2)
agv.stop()
time.sleep(1)

print("Rotating left in place...")
agv.turn_left(speed)
time.sleep(2)
agv.stop()
time.sleep(1)

print("Translating laterally to the right...")
agv.move_right_lateral(speed)
time.sleep(2)
agv.stop()

# Task complete; power off the robot and disable the motors
agv.power_off()
```
