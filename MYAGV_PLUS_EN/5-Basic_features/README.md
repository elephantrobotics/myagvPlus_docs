# Basic Functions

**This chapter mainly explains the basic functions of the product and the use of basic software. This chapter is very important and should be read carefully. Before actually using the robot, please make sure to correctly understand the operations described.**

- [5.1 myblockly](5.1-myblockly/README.md)<br>

  myBlockly is a fully visual modular programming software and a graphical programming language. The myBlockly interface is simple and the programming functions are comprehensive. Its visual programming method is suitable for users who are new to robot products.

- [5.2 myStudio](5.2-mystudio/README.md)<br>

  myStudio is a one-stop platform for using robots like myAGV Plus. Users can choose different firmwares according to their usage scenarios and download them, while also being able to learn related materials online and watch instructional videos, which is very convenient.

- [5.3 myagv_UI](5.3-myagv_UI/user_manual.md)

  MyAGV_UI software is specially designed to work with MyAGV Plus products. It lowers the user threshold through a graphical interface, allowing users to quickly understand MyAGV Plus with just a click. It can start MyAGV Plus sensor communication and SLAM with one click, swap the rear LED lights, and also includes functions to test motors and cameras.

- [5.4 Custom Robot Operating System](5.4-SystemInstructionManual.md)

  The myAGV Plus system not only includes environments like ROS2 and Python, but also provides robot development software such as VSCode, VNC, and SSH without complicated setup. It also offers automatic software updates and supports one-click updates for the corresponding development environment.

- [5.5 System Image Burning](5.5-System_Image.md)

  myAGV Plus comes with a proprietary customised Ubuntu AArch64 system image, pre-installed with complete ROS 2 Humble, drivers, development tools, and teaching cases. There’s no need to manually configure the environment; you just need to complete one-click burning using the HDD Raw Copy Tool, making it simple and efficient.
