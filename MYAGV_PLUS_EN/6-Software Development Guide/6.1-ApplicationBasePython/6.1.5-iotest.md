# IO State Reading and Peripheral Control

The AGVPlus motherboard provides a set of IO interfaces for peripherals. You can use these interfaces to read input signals (such as the emergency stop button) or output high/low-level signals to control external relays, air pumps, and the chassis fan.

## 1 Interface Description

Controlling IO and peripherals mainly involves the following four interfaces:

- `get_pin_input(pin)`: Read the state of the input pins on the motherboard. The `pin` range is `0-6` (0 represents all pins). The return value is `0` (low level, hardware default), `1` (high level), or `-1` if the reading fails.
- `set_pin_output(pin, state=0)`: Control the level of the output pins on the motherboard. The `pin` range is `0-6`. Pass `0` to the `state` parameter to output a low level (default), or `1` for a high level.
- `get_estop_state()`: Independently obtain the state of the chassis emergency stop button. Returns `0` (released/low level), `1` (pressed/high level), or `-1` if the reading fails.
- `set_fan_state(state=1)`: Control the chassis cooling fan switch. Pass `0` to the `state` parameter to turn it off, or `1` to turn it on (hardware default is on).

## 2 Simple Demonstration

Create a new Python file named `io_test.py` and enter the following code:

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# Initialize the MyAGVPlus object
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# IO and peripherals are directly controlled by the motherboard, so powering on the relay is sufficient for testing
agv.power_on_only()

print("--- Starting Fan and Peripheral Output Test ---")
print("Turning off the fan for 3 seconds...")
agv.set_fan_state(0)
time.sleep(3)

print("Turning the fan back on...")
agv.set_fan_state(1)
time.sleep(1)

print("Setting output pin 1 to high level (1)...")
agv.set_pin_output(1, 1)
time.sleep(2)
print("Restoring output pin 1 to low level (0)...")
agv.set_pin_output(1, 0)
time.sleep(1)

print("\n--- Starting Input Pin and E-Stop State Test ---")
# Test reading the input state of pin 2
pin2_state = agv.get_pin_input(2)
print(f"Current input state of pin 2: {pin2_state}")

# Test reading the emergency stop button state
estop = agv.get_estop_state()
if estop == 1:
    print("Warning: The emergency stop button is currently [Pressed]!")
elif estop == 0:
    print("Normal: The emergency stop button is currently [Released].")
else:
    print("Failed to read the emergency stop state.")

# Test completed, turn off the power
agv.power_off()
```

## 3 Run the Example File

Run the code by entering the following command in the terminal:

```bash
python3 io_test.py
```

After execution, you can clearly hear the sound of the chassis fan turning off and back on. Meanwhile, the terminal will print the real-time states of the corresponding pins and the emergency stop button.
