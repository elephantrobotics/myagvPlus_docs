6.2.1 安装和环境搭建

ROS2 安装

  • 1.配置 Ubuntu 资源库

配置 Ubuntu 软件源，允许使用 "restricted"、"universe "和 "multiverse"。您可以按照 Ubuntu 指南 获取相关说明。

  • 2.设置来源列表

设置计算机以接受来自 packages.ros.org 的软件。

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
  • 3.设置钥匙
sudo apt install curl -y
curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
  • 4.安装

首先，确保你的 Debian 软件包索引是最新的：

sudo apt update

现在，选择要安装哪种 ROS2,以下以ROS2 humble为例。

Desktop-Full Install: (推荐) : 所有桌面功能 + 模拟器、3D 可视化、导航、感知全套工具

sudo apt install ros-humble-desktop-full

Desktop Install: ROS2-Base 中的所有内容，以及以下工具 rqt 和 rviz2

sudo apt install ros-humble-desktop

ROS2-Base: (Bare Bones) ROS 2 核心打包、构建、通信库。无图形界面工具

sudo apt install ros-humble-ros-base

ROS 中还有更多可用的软件包。您可以直接安装特定软件包。

sudo apt install ros-humble-PACKAGE

e.g.

sudo apt install ros-humble-slam-toolbox

要查找可用软件包，请参阅 ROS2 Index 或使用

apt search ros-humble
  • 5.环境设置

您必须在每一个使用 ROS2 的bash终端中编写这个脚本。

source /opt/ros/humble/setup.bash

每次启动新 shell 时，自动为该脚本提供源代码会很方便。这些命令可以帮你做到这一点。

Bash

echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
