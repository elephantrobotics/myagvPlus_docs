6.1.5 IO 状态读取与外设控制

IO 状态读取与外设控制

AGVPlus 底盘主板提供了一组针对外设的 IO 接口，您可以利用这些接口读取输入信号（如急停按钮），或输出高低电平信号控制外部继电器、气泵以及底盘风扇。

1 接口说明

控制 IO 和外设主要涉及以下四个接口：

  • get_pin_input(pin): 读取主板上的输入引脚状态。pin 范围为 0-6（0代表所有引脚）。返回值为 0（低电平，硬件默认），1（高电平），读取失败返回 -1。
  • set_pin_output(pin, state=0): 控制主板上输出引脚的电平。pin 范围 0-6。state 传入 0 为低电平（默认），1 为高电平。
  • get_estop_state(): 独立获取底盘急停按钮的状态。返回 0（未按下/低电平），1（已按下/高电平），-1 为读取失败。
  • set_fan_state(state=1): 设置底盘散热风扇的开关。state 传入 0 为关闭，1 为开启（硬件默认值为开启）。

2 简单演示

创建一个新的 Python 文件 io_test.py，并输入以下代码：

from pymycobot.myagvplus import MyAGVPlus
import time

# 初始化 MyAGVPlus 对象
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyACM0', esp32_baud=115200, debug=True)

# IO 与外设由底层主板直接控制，测试时开启继电器供电即可
agv.power_on_only()

print("--- 开始风扇与外设输出测试 ---")
print("关闭风扇 3 秒...")
agv.set_fan_state(0)
time.sleep(3)

print("重新开启风扇...")
agv.set_fan_state(1)
time.sleep(1)

print("设置 1 号输出引脚为高电平(1)...")
agv.set_pin_output(1, 1)
time.sleep(2)
print("恢复 1 号输出引脚为低电平(0)...")
agv.set_pin_output(1, 0)
time.sleep(1)

print("\n--- 开始输入引脚与急停状态测试 ---")
# 测试读取 2 号引脚的输入状态
pin2_state = agv.get_pin_input(2)
print(f"当前 2 号引脚的输入状态: {pin2_state}")

# 测试读取急停按钮状态
estop = agv.get_estop_state()
if estop == 1:
    print("注意: 急停按钮当前处于【按下】状态！")
elif estop == 0:
    print("正常: 急停按钮当前处于【释放】状态。")
else:
    print("读取急停状态失败。")

# 运行完毕，切断电源
agv.power_off()

3 运行示例文件

在终端中输入以下命令运行代码：

python3 io_test.py

执行后，您可以明显听见底盘风扇关闭和重新开启的声音变化，同时终端会打印出对应引脚和急停按钮的实时读取状态。
