# 配置

pymycobot 是一个 Python 软件包，用于与小车进行串行通信。它支持 Python2、Python3.5 及更高版本。

使用 pymycobot 之前，请确保构建了 Python 环境。按照以下步骤安装 Python。

## 1 下载和安装 Python

目前，Python 有两个版本：2.x 和 3.x。这两个版本互不兼容。本节以版本 `3.x` 为例，因为它越来越受欢迎。

### 1.1 安装 Python

Jetson Nano 版本自带 Ubuntu（V-22.04）系统和内置 Python 开发环境，因此无需单独构建和管理。

## 2 准备工作

在终端中输入以下命令进行安装或更新：

```bash
pip install --upgrade pymycobot
```

![pipinstall](../../resources/6-SDKDevelopment/6.1/pipinstall.png)

## 3 简单演示

创建一个新的 Python 文件，并输入以下代码。

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# 初始化 MyAGVPlus 对象
# 注意需要传入电机控制串口和ESP32的串口，具体串口路径视设备实际情况而定
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyUSB0', esp32_baud=115200, debug=True)

# 开启机器人（自动开启继电器上电并使能电机，调用后程序内置了约6秒等待让电机启动和校准）
agv.power_on()

# 设置移动速度 (范围为 0.01 到 1.50 m/s)
speed = 0.5 

print("向前移动")
agv.move_forward(speed)
time.sleep(2)  # 持续 2 秒
agv.stop()
time.sleep(0.5)

print("向后移动")
agv.move_backward(speed)
time.sleep(2)
agv.stop()
time.sleep(0.5)

print("左横向移动")
agv.move_left_lateral(speed)
time.sleep(2)
agv.stop()
time.sleep(0.5)

print("右横向移动")
agv.move_right_lateral(speed)
time.sleep(2)
agv.stop()

# 运行完毕，关闭机器人电源并禁用电机
agv.power_off()
```

## 4 运行示例文件：

```bash
python3 move_agv.py
```

默认情况下，该示例脚本会控制 AGV 向四个不同的方向各移动 2 秒钟。
