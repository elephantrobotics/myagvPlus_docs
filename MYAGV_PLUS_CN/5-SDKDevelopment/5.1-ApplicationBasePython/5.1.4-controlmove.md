# 控制小车移动

通过 `MyAGVPlus` 提供的运动控制接口，您可以方便地控制全向麦克纳姆轮底盘进行平移、后退以及原地旋转等操作。

## 1 接口说明

所有的移动指令均需要传入 `speed`（速度）参数，该参数的合法有效范围为 **0.01 到 1.50 (m/s)**。出于安全考虑，如果速度设置越界，系统将报错。

常用运动接口如下：
- `move_forward(speed)`: 控制小车向前平移
- `move_backward(speed)`: 控制小车向后平移
- `move_left_lateral(speed)`: 控制小车向左横向平移
- `move_right_lateral(speed)`: 控制小车向右横向平移
- `turn_left(speed)`: 控制小车原地左转
- `turn_right(speed)`: 控制小车原地右转
- `stop()`: 紧急刹车停止所有运动，车轮速度瞬间归零

## 2 简单演示

创建一个新的 Python 文件 `control_move.py`，并输入以下代码：

```python
from pymycobot.myagvplus import MyAGVPlus
import time

# 初始化 MyAGVPlus 对象
agv = MyAGVPlus('/dev/myagvplus_controller', baudrate=921600, esp32_port='/dev/ttyUSB0', esp32_baud=115200, debug=True)

# 开启机器人（继电器上电并使能电机，需等待约 6 秒让电机启动）
agv.power_on()

speed = 0.5 # 设置统一运动速度 0.5 m/s

print("向前平移...")
agv.move_forward(speed)
time.sleep(2)
agv.stop()
time.sleep(1)

print("原地左转...")
agv.turn_left(speed)
time.sleep(2)
agv.stop()
time.sleep(1)

print("向右横移...")
agv.move_right_lateral(speed)
time.sleep(2)
agv.stop()

# 运行完毕，关闭机器人电源并禁用电机
agv.power_off()
